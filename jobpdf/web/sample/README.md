# Sample CV (JM-52)

Put the CV for the upload page's "Try a sample CV" button here as `sample_cv.pdf` (or
`sample_cv.docx`): a PDF or DOCX of at most 5 MB. Without it the button does not appear.

The file is public. Anyone can download it from the repository and from `/sample-cv` on the
server, so it must be made up or scrubbed: no real name, address, phone number, email or photo.
